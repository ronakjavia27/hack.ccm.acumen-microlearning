# Recommendations of antiplatelet therapy during stroke management and post IVT EVT during discharge

The 2026 AHA/ASA stroke guideline restructures antiplatelet therapy into distinct phases — acute administration, post-IVT/EVT initiation timing, and discharge/secondary prevention — with significant expansions in DAPT eligibility, pharmacogenomic-guided selection, and explicit "harm" designations for several previously used agents.[^3_1][^3_2]

***

## Acute Aspirin Administration

### General Principle (Non-IVT Patients)

| Recommendation | COR/LOE | Detail |
| :-- | :-- | :-- |
| Aspirin within 48h of stroke onset | COR 1, LOE A | Reduces death and dependency (IST, CAST trials) [^3_1] |
| Preferred over oral anticoagulation for noncardioembolic AIS/TIA | COR 1, LOE A | Minimizes bleeding risk while reducing recurrent stroke [^3_1] |
| Individualized agent selection | COR 1, LOE C-EO | Based on risk profile, cost, tolerance, relative efficacy [^3_1] |

### For Patients Who Received IVT

| Timing | Recommendation | COR/LOE | Rationale |
| :-- | :-- | :-- | :-- |
| First 24h post-IVT | **Hold all antiplatelets**; risk is "uncertain" | COR 2b, LOE B-NR | May be considered only if concomitant condition provides substantial benefit or withholding causes substantial risk [^3_1] |
| After 24h (repeat CT confirms no hemorrhage) | Start aspirin 325 mg | Standard practice | Hemorrhagic transformation risk excluded [^3_1][^3_3] |
| After 24h post-EVT (no IVT) | Start aspirin after imaging confirmation | Standard practice | Same principle; EVT alone has lower ICH risk but imaging confirmation still required [^3_4] |

### Key Clinical Principle

The 24-hour hold is not an absolute prohibition — it is a risk-uncertainty designation. In patients with acute coronary syndrome requiring antiplatelet therapy, concurrent IV antiplatelet use may be justified despite IVT, but this is a COR 2b decision requiring individualized risk-benefit assessment.[^3_1]

***

## Antiplatelet Agents Now Classified as Harmful

| Agent | COR/LOE | Rationale |
| :-- | :-- | :-- |
| IV abciximab | COR 3: Harm, LOE B-R | Increased bleeding complications; AbESTT-II trial terminated early [^3_1] |
| IV tirofiban | COR 3: Harm, LOE B-R | Efficacy not established; hemorrhagic risk [^3_1] |
| Triple antiplatelet therapy (aspirin + clopidogrel + dipyridamole) | COR 3: Harm, LOE B-R | Increased bleeding without outcome benefit [^3_2] |
| Routine antiplatelet addition to OAC in AF (without active CAD or stent) | COR 3: Harm, LOE B-NR | Bleeding risk outweighs benefit [^3_2] |
| Ticagrelor over aspirin for NIHSS ≤3 minor stroke | COR 3: No Benefit, LOE B-R | THALES subgroup: no superiority over aspirin for composite endpoint [^3_1] |


***

## Dual Antiplatelet Therapy (DAPT) — Expanded Criteria

The 2026 guideline substantially broadened DAPT eligibility compared to 2018, expanding both the NIHSS threshold and the treatment window.

### DAPT Protocol A: Clopidogrel + Aspirin (Standard)

| Parameter | 2026 Recommendation | 2018 Guideline |
| :-- | :-- | :-- |
| NIHSS threshold | ≤3 (primary) or ≤5 with LAA etiology | ≤3 only |
| Window from onset | Within 24h (primary); 24–72h if LAA etiology | Within 24h only |
| Loading dose | Clopidogrel 300–600 mg + aspirin 300–325 mg | Clopidogrel 300 mg + aspirin 75–300 mg |
| Duration | 21 days → then SAPT | 21 days → then SAPT |
| COR/LOE | COR 1, LOE A (NIHSS ≤3, within 24h) | COR 1, LOE A |
| COR/LOE (extended window, LAA) | COR 2a, LOE B-R (NEW — high impact) | Not addressed [^3_2] |
| Key trials | CHANCE, CHANCE-2, POINT | CHANCE, POINT |

### DAPT Protocol B: Ticagrelor + Aspirin (Selected Indications)

| Parameter | Recommendation |
| :-- | :-- |
| Eligibility | NIHSS ≤5, ABCD2 ≥6, or symptomatic ≥50% intracranial/extracranial stenosis |
| Window | Within 24h of onset |
| Duration | 30 days → then SAPT |
| COR/LOE | COR 2b, LOE B-R |
| Key trial | THALES (HR 0.83 for stroke/death) [^3_2] |

### DAPT Protocol C: Pharmacogenomic-Guided (CYP2C19 LOF)

| Parameter | Recommendation |
| :-- | :-- |
| Eligibility | NIHSS ≤3, ABCD2 ≥4, within 24h, CYP2C19 loss-of-function allele carrier |
| Regimen | Ticagrelor + aspirin × 21 days → ticagrelor monotherapy |
| COR/LOE | COR 2b, LOE B-R |
| Rationale | Clopidogrel is a prodrug requiring CYP2C19 activation; LOF carriers have reduced active metabolite → reduced antiplatelet effect |
| Key trial | CHANCE-2 (ticagrelor superior to clopidogrel in LOF carriers) [^3_2] |

### When DAPT Should NOT Be Used

| Scenario | Recommendation |
| :-- | :-- |
| Cardioembolic stroke (AF) | Use OAC, not DAPT [^3_2] |
| Moderate-severe stroke (NIHSS >5) | SAPT only; DAPT bleeding risk excessive |
| Post-IVT within 24h | Hold; initiate after 24h CT clearance [^3_1] |
| Duration >21 days (clopidogrel-based) | Not recommended; bleeding risk increases after 21 days (POINT trial) [^3_2] |
| Duration >30 days (ticagrelor-based) | Not recommended beyond 30 days [^3_2] |

## Antiplatelet Therapy at Discharge

### Discharge Antiplatelet Selection by Stroke Etiology

| Etiology | Discharge Regimen | Duration | COR/LOE |
| :-- | :-- | :-- | :-- |
| Noncardioembolic, minor stroke (completed 21-day DAPT) | SAPT: aspirin OR clopidogrel OR aspirin-dipyridamole | Long-term (lifelong) | COR 1, LOE A [^3_1] |
| Noncardioembolic, moderate-severe stroke (no DAPT) | SAPT: aspirin 325 mg (or clopidogrel 75 mg if aspirin-intolerant) | Long-term | COR 1, LOE A [^3_1] |
| Cardioembolic (AF) | OAC (DOAC preferred); NO routine antiplatelet addition | Long-term | COR 3: Harm for antiplatelet addition [^3_2] |
| Large artery atherosclerosis (intracranial) | Aspirin 325 mg + cilostazol 200 mg BID (if tolerated) | Long-term | SAMMPRIS: superior to stenting [^3_1] |
| Extracranial carotid/vertebral dissection | Antiplatelet OR anticoagulant for ≥3 months → then individualize | ≥3 months | COR 2a, LOE B-R [^3_1] |
| Cryptogenic (ESUS) | SAPT (aspirin); empirical DAPT NOT recommended | Long-term | COR 1, LOE A; NAVIGATE-ESUS, RE-SPECT-ESUS showed DOAC no better [^3_1] |
| Recent stent (e.g., coronary) | OAC + antiplatelet (clopidogrel preferred over aspirin) | Per cardiology guidance | Individualized [^3_2] |

### Post-IVT/EVT Discharge Transition Protocol

| Time Point | Action | Rationale |
| :-- | :-- | :-- |
| 0–24h post-IVT | No antiplatelet | Hemorrhagic transformation risk [^3_1] |
| 24h post-IVT | Repeat non-contrast CT; if no ICH → start aspirin 325 mg | Exclude hemorrhagic transformation [^3_1][^3_4] |
| 24–48h post-IVT/EVT | If minor non-disabling stroke (NIHSS ≤5, noncardioembolic, no IVT) → consider DAPT | Prevent early recurrence [^3_2] |
| Day 21 (if on DAPT) | Transition DAPT → SAPT (clopidogrel or aspirin) | POINT trial: bleeding risk increases beyond 21 days [^3_2] |
| Discharge (moderate-severe stroke) | SAPT: aspirin 325 mg daily OR clopidogrel 75 mg daily | Long-term secondary prevention [^3_1] |
| Discharge (AF, no stent) | DOAC alone; NO antiplatelet | COR 3: Harm for combination [^3_2] |

## Special Population Considerations

### Patients Already on Aspirin at Stroke Onset

| Question | Recommendation | COR/LOE |
| :-- | :-- | :-- |
| Increase aspirin dose? | Not well established | COR 3: No Benefit, LOE B-R [^3_1] |
| Switch to different antiplatelet? | Not well established | COR 3: No Benefit [^3_1] |
| Clinical practice | Consider DAPT if eligible (minor stroke, noncardioembolic) or switch to clopidogrel if aspirin failure suspected | Individualized [^3_1] |

### Arterial Dissection

| Parameter | Recommendation |
| :-- | :-- |
| Duration | ≥3 months of antiplatelet OR anticoagulant |
| COR/LOE | COR 2a, LOE B-R |
| Agent choice | Either approach reasonable; no proven superiority |
| Beyond 3 months | Individualize based on imaging and recurrence risk [^3_1] |

### Intracranial Atherosclerotic Disease (ICAD)

| Parameter | Recommendation |
| :-- | :-- |
| Medical therapy | Aspirin 325 mg + cilostazol 200 mg BID |
| Stenting | NOT recommended as first-line (SAMMPRIS: higher peri-procedural morbidity) |
| Additional risk factor | Aggressive BP control (<130/80) and statin (LDL <70 mg/dL) |


***

## Key Clinical Pearls

1. **The 21-day rule is critical.** DAPT with clopidogrel + aspirin must stop at 21 days — the POINT trial demonstrated that continued DAPT beyond 21 days increases major hemorrhage without additional benefit.[^3_2]
2. **CYP2C19 genotyping changes practice.** In LOF allele carriers, clopidogrel is less effective; ticagrelor + aspirin is now a reasonable alternative (CHANCE-2). This is the first pharmacogenomic-guided antiplatelet recommendation in stroke guidelines.[^3_2]
3. **Post-IVT antiplatelet initiation is not a blanket 24-hour rule.** The guideline uses "uncertain" (COR 2b) rather than "harmful" — meaning clinical judgment applies when concomitant conditions (e.g., ACS) require antiplatelet therapy.[^3_1]
4. **Never add antiplatelets to OAC in AF** unless there is active CAD or a recent stent. This is now a COR 3: Harm recommendation.[^3_2]
5. **Ticagrelor is NOT superior to aspirin** for minor stroke (NIHSS ≤3) as monotherapy — the benefit of ticagrelor is only in combination with aspirin for 30 days in select high-risk patients (THALES).[^3_1][^3_2]
6. **DAPT window extended to 72 hours** for LAA etiology — previously, DAPT had to start within 24h; the 2026 guideline extends this to 72h if the mechanism is atherosclerotic (≥50% stenosis).[^3_2]
7. **Post-EVT without IVT**: antiplatelet timing is more flexible — the 24-hour hold applies primarily to IVT patients. EVT-only patients may start aspirin earlier if imaging confirms no hemorrhage, though most centers still perform a 24h CT before initiation.[^3_4]
